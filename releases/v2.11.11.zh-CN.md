# Prompt Optimizer v2.11.11

## 概括
- 新增 CTF、编程、取证三类解题专用优化模板（中英双语，共 6 个），并把通用、分析、迭代与用户提示词模板改写为「解题任务简报」结构。
- Windows 桌面端启用现代无边框窗口：移除原生标题栏，保留右上角系统三键，标题栏配色随应用主题实时同步。
- 产品定位收窄为解题提示词优化：隐藏图像模式入口，历史遗留的图像模式偏好与路由自动回落到基础模式。
- 应用内品牌名更新为「解题提示词优化器 / Solver Prompt Optimizer」，中、繁、英三语界面与 Web、扩展入口页同步。

## 亮点
- 新增三类解题模板后，可针对 CTF（Web / Pwn / Reverse / Crypto / Misc / Forensics）、编程与算法题、电子取证与数据分析直接产出结构化任务简报，模板内已内置各方向的排查路径与工具链提示。
- 优化结果要求「结论先行 + 可复现」：模板显式约束不得编造漏洞或数据，信息不足时改为输出按优先级排列的排查步骤与待补信息清单。
- Windows 窗口更紧凑：页头整体成为拖拽热区、双击可最大化，按钮区自动避让系统三键；浅色、深色及其余四套主题下标题栏与界面不再出现割裂色带。
- 图像模式入口隐藏后，导航与路由不再暴露 `/image/*` 工作区，降低误操作。

## 产品更新

### Desktop
- Windows 平台启用 `titleBarStyle: 'hidden'` 与 `titleBarOverlay`，移除原生标题栏、保留系统最小化 / 最大化 / 关闭按钮，overlay 高度 36px；非 Windows 平台行为完全不变。
- 新增 `window-set-title-bar-overlay` IPC 通道：仅接受 `color` / `symbolColor` / `height` 三个字段，主进程做白名单校验后才调用 `setTitleBarOverlay`；非 Windows 平台或窗口已销毁时安全返回失败。
- preload 暴露 `electronAPI.window.setTitleBarOverlay`，渲染进程类型声明补充 `WindowAPI` 与 `TitleBarOverlayOptions`。
- 新增 `packages/ui/src/utils/window-controls-overlay.ts`：维护 6 套主题 × 2 种表面（页头 / 助手选择页）的 overlay 配色表；仅在 `navigator.windowControlsOverlay.visible` 为真时动作，浏览器与扩展环境自动 no-op。
- 主布局页头设为拖拽热区，导航与操作容器整体排除拖拽；助手选择页是裸布局，额外提供 36px 顶部拖拽条。
- 路由在「主布局 ↔ 助手选择页」之间切换、以及切换主题时，按当前表面重新同步 overlay 配色。
- 启用 `autoHideMenuBar` 隐藏菜单栏；应用菜单及其快捷键（缩放、刷新、DevTools、全屏）仍正常注册生效。
- 图像模式入口默认隐藏（`FunctionModeSelector` 新增 `showImageMode`，默认 `false`）。
- 遗留的图像模式偏好自动回落基础模式，避免进入已隐藏的工作区。

### Web
- 入口页标题更新为「解题提示词优化器」。
- 图像模式入口隐藏与路由回落逻辑在 Web 端同样生效，`/image/*` 不再作为可进入的默认路由。

### Extension
- 版本号随本次发布同步至 2.11.11，扩展入口页标题同步更新。

### Core/Infra
- 新增 6 个内置模板：`ctf-solve-optimize`、`programming-solve-optimize`、`forensics-solve-optimize` 及各自 `_en` 版本，并注册进 `ALL_TEMPLATES`。
- 将 `general-optimize`、`analytical-optimize`、`iterate` 与 `user-prompt-basic / planning / professional` 六个模板（中英共 12 个文件）由「角色设定 Profile」式结构改写为「解题任务简报」式结构。
- 三语（zh-CN / zh-TW / en-US）文案同步更新：品牌名、启动页助手描述、提示词输入占位符与帮助文本统一改为解题导向。
- `.gitignore` 新增 `.tmp-verify/` 规则。

## 修复
- 修复无边框窗口下无法拖动窗口的问题：为主布局页头与助手选择页提供拖拽热区，同时保证按钮区为 `no-drag`，避免交互元素失去点击响应。
- 修复系统三键与页头操作按钮重叠的问题：overlay 生效时（`display-mode: window-controls-overlay`）页头右侧按 `titlebar-area-width` 让出安全距离。
- 修复切换主题后标题栏底色与界面割裂的问题：按当前路由对应的表面（页头 / 页面背景）分别取色同步。
- 修复历史记录中遗留的图像模式偏好会进入已隐藏工作区的问题，统一回落基础模式。

## 破坏性变更 / 升级说明
- 图像模式（`/image/*`）入口在本版本中隐藏：已保存的图像模式偏好会自动回落为基础模式，图像相关工作区不再可达。
- 应用内品牌名由「Frieren assistant」变更为「解题提示词优化器」（英文为 Solver Prompt Optimizer）；发行包文件名与仓库名保持不变。
- 升级无需迁移用户数据：自定义模型配置、提示词与历史记录保持原样。
- 本地开发与构建仍要求 Node.js 24。
